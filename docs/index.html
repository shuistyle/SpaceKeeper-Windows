Name your desktops.
Jump straight to them.

SpaceKeeper is a small app in your notification area that shows all your virtual desktops as tiles. Name them, colour-code them, pin their order and switch with one click.

Also for Mac and ChromeOS.

Everything Task View should let you do

Windows calls your desktops “Desktop 1, Desktop 2…” and hides them behind Task View. SpaceKeeper puts them all in one panel, a double tap of Ctrl away.

  • Name every desktop

    Double-click a tile and type. Windows stores the name, so it also appears in Task View (Win+Tab).

  • Jump in one click

    Click a tile to go to that desktop, even with PowerPoint or another Office app in front. A short banner shows where you've arrived.

  • Colour-code them

    Right-click a tile to fill it with one of ten colours chosen for colour blindness. Each has its own symbol and keeps text at 7:1 contrast.

  • Pin their order

    Pin important desktops. If one gets dragged out of place in Task View, SpaceKeeper tells you where it belongs.

  • Add and remove desktops

    Add a desktop with one click (or Ctrl+N). Removing one moves its windows to a neighbouring desktop, so nothing is closed.

  • Open from anywhere

    Double-tap Ctrl in any app (or press Ctrl+Alt+S) to open the panel. Esc closes it.

  • Your own order

    Drag tiles to keep related desktops together. It's SpaceKeeper's order only; Task View isn't changed.

  • Stays out of the way

    Nothing sits on top of your apps or web pages. SpaceKeeper lives in the notification area until you call it.

Safe by design, honest about limits

What it does

  • Uses Windows' own virtual desktops: names, switching, adding and removing all go through Windows
  • Installs into your own user folder. No administrator rights, no system changes.
  • The double-tap shortcut only watches the Ctrl key, and passes every key straight on. Nothing you type is recorded.
  • Stores names, colours and settings on your PC only. No accounts, no tracking, no network apart from installing.
  • Every download is checked against its published SHA-256 checksum before it's installed

Worth knowing

  • Windows 11 only.
  • Windows has no official desktop API for apps, so SpaceKeeper uses a well-maintained open-source library. A big Windows update can need a SpaceKeeper update.
  • It isn't code-signed (that costs hundreds of pounds a year), which is why it installs with a PowerShell command instead of a download.
  • Double-tap Ctrl doesn't work while an app running “as administrator” is in front. Ctrl+Alt+S still does.

Accessibility

Built to work with Windows' accessibility settings, not around them.

  • Screen readers

    Narrator, NVDA and JAWS read each tile as one clear summary, such as “Teaching, Desktop 2, colour Navy”, and announce every switch.

  • Keyboard only

    Arrow keys move between tiles, Enter switches, F2 renames, Alt+Shift+arrows reorder and Delete removes.

  • Vision

    Four tile sizes (Ctrl+Plus/Minus), Windows text size respected, and contrast themes use your own colours. Nothing relies on colour alone.

  • Motion

    With Animation effects off, nothing slides or fades and the switch banner stays up longer.

Install

Takes about a minute. No administrator rights, and no “Windows protected your PC” warning.

  1. Open Terminal

    Press Win+X and choose Terminal. (Command Prompt or PowerShell work too.)

  2. Paste this command and press Enter

    powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((iwr -UseBasicParsing https://raw.githubusercontent.com/shuistyle/SpaceKeeper-Windows/main/install.ps1).Content))"

    It downloads the right version for your PC, checks it against its published checksum (and stops if it doesn't match), installs it, adds it to the Start menu and starts it.

  3. Find it in the notification area

    SpaceKeeper's icon appears at the right of the taskbar (click ^ if it's hidden). Click it, or double-tap Ctrl, to open the panel. In Settings, turn on Launch at sign-in so it starts with Windows.

Updating or removing SpaceKeeper

To update, run the same command again. Your names, colours and settings are kept.

To remove it, run the command with -Uninstall added just before the final quote mark:

powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((iwr -UseBasicParsing https://raw.githubusercontent.com/shuistyle/SpaceKeeper-Windows/main/install.ps1).Content)) -Uninstall"

Is it safe to paste a command?

Only paste commands from sources you trust. This one downloads install.ps1 from SpaceKeeper's GitHub page, which you can read first. “ExecutionPolicy Bypass” applies to this one run only.

Prefer to download it yourself?

Download the zip for your PC from the latest release (x64 for Intel and AMD, arm64 for Arm PCs such as Snapdragon laptops). Right-click it › Properties › tick Unblock, extract it, run SpaceKeeper.exe and click Install in its panel. The release's SHA256SUMS.txt lets you check the download.

Questions

Why a command instead of a normal download?

Windows shows a “Windows protected your PC” warning for apps downloaded in a browser unless they're code-signed, which costs hundreds of pounds a year. The PowerShell command avoids that warning and checks the download's checksum instead, which gives the same protection against a damaged or tampered file.

Does it need administrator rights?

No. It installs into your own user folder (%LOCALAPPDATA%\Programs\SpaceKeeper), which only your Windows account can change.

Does it collect any data?

No. SpaceKeeper doesn't connect to the internet while it runs. Names are stored by Windows itself; colours, pins and settings stay in a file on your PC.

Does it work with more than one monitor?

Yes. Windows desktops span all your monitors, so one grid covers them all.

Will it work at school or work?

Usually. If your organisation uses Smart App Control or blocks unsigned apps, ask your IT team, who can review the code on GitHub.

Something isn't working. What should I do?

Open the panel, expand Diagnostics and click Copy report, then open an issue on GitHub with it.
